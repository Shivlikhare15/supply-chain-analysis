# 📦 Supply Chain Analysis & Delivery Risk Prediction

## 📌 Project Overview
This project focuses on analyzing supply chain operations and identifying the root causes of delivery delays in a global e-commerce business.

The analysis includes:
- Delivery performance analysis
- Profitability analysis
- Bottleneck detection
- Time-based delay trends
- Machine Learning prediction model for late deliveries

A Random Forest Classifier was used to predict delivery risk with 74% accuracy.

---

# 📊 Key Insights

- Total Orders Analyzed: 172,765
- Late Delivery Rate: 54.71%
- On-Time Delivery Rate: 45.29%
- Profit at Risk due to Delays: $2.1M
- Random Forest Accuracy: 74%
